# 小航宝的航天乐园

启智·融趣——航天知识智能体。面向小学 1–6 年级的中文航天科普单页应用。

纯前端运行，不需要登录，也不需要任何 API Key。孩子的年级、简明/普通模式、闯关星星与探索记录都保存在浏览器的 `localStorage` 里。

## 本地运行

需要已安装 [Node.js](https://nodejs.org/)（建议 18 及以上）。

```bash
npm install
npm run dev
```

浏览器打开终端提示的本地地址（默认 `http://localhost:5173`）。

生产构建：

```bash
npm run build
npm run preview
```

`npm run build` 会先做 TypeScript 检查，再输出到 `dist/`。

## 功能一览

1. **星空探索首页**  
   明亮星空背景、吉祥物小航宝、1–6 年级选择，以及六个入口：开始提问、航天闯关、航天故事、今日冷知识、知识地图、我的探索记录。

2. **航天问答**  
   对话界面 + 快捷问题（火箭为什么能飞？月亮为什么不会掉下来？宇航员怎么睡觉？火星上有水吗？）。  
   回答结构：短答案 → 生活比方 → 例子 → 追问。低年级和简明模式句子更短。遇到不合适的问题会温和地转到安全话题；拿不准时会说：「这个问题我现在还不能确定，我们可以一起查可靠的资料。」

3. **今日航天冷知识**  
   20 余条短小、准确的航天事实，可按日轮换，也可一条条翻看。

4. **航天知识闯关**  
   ★ / ★★ / ★★★ 三档，选择题 + 判断题。答对点亮星星，全对获得徽章，反馈始终正向。进度写入 `localStorage`。

5. **航天故事**  
   第一人称、点一下再往下：小小航天员、火箭设计师、月球车司机、空间站科学家、火星探险员。

6. **知识地图**  
   可点击：太阳、地球、月球、火箭、卫星、空间站、火星。

7. **探索记录**  
   问答、闯关、故事、冷知识、地图足迹，以及星星与徽章墙。

8. **家长/教师面板**  
   简明模式与普通模式说明，附一节「纸火箭」课堂提纲（材料、步骤、科学要点、讨论与安全）。

## 技术栈

- Vite
- React 18
- TypeScript
- Tailwind CSS

界面为简体中文（`zh-CN`）。视觉以薄荷绿、天空青与鸢尾紫（`#5EEAD4` / `#38BDF8` / `#818CF8`）为主，统一双色线性图标、玻璃拟态卡片，星空背景偏明亮，不走阴暗厚重路线。

## 使用建议

- 先在首页选年级，再进入问答或闯关，讲解长度会跟着年级变化。
- 课堂里可打开家长/教师面板，按纸火箭提纲做动手活动。
- 科学内容面向小学，力求正确、温和，不替代教材或专业资料。
